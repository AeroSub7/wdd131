Site Plan

Site Name: AeroSub Satisfactory

The site name that I chose is AeroSub Satisfactory. I chose this because AeroSub is my gamer tag/ user name and Satisfactory is the computer game that I am going to talk about my history with.

Site Purpose:

The purpose is to be a website about my experience with the computer game Satisfactory, which is my favorite game. This site will help to show how important the game is to me and also be a place to showcase my different factories in it with pictures.

Scenarios:

  • How important is Satisfactory to AeroSub?
  • What has AeroSub done in the game?
  • What is the game like?
  • What is the game about?
